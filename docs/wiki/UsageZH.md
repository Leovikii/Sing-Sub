# 资源、配置与同步

[English](Usage) · [首页](HomeZH)

## 资源与配置

在资源库中保存节点集、模板和规则集。点击卡片预览，点击编辑按钮修改名称、备注或内容；保存后才会生效。配置选择模板与节点集，通过筛选规则生成订阅内容。

节点与模板使用 JSON 编辑器，支持格式化、校验、查找与替换。规则集使用结构化编辑器，远程 HTTPS 来源放在 SOURCE，手写规则放在对应域名区块。

## 两种更新时间

- 所有资源卡片底部的时间记录该配置文件在本站成功保存的时间，包括名称、备注与内容修改。它不是每个节点的独立历史，也不是编译时间。
- 远程规则的“来源更新”保留在规则集编辑窗口 SOURCE 区域左下角，与更新周期相邻。它表示最近一次成功抓取，不代表上游内容一定变化；多来源时，下方同时列出各来源的时间。
- 近期显示“几分钟前 / 几小时前 / 几天前”，满 30 天显示本地日期与时分。聚焦或触摸时间可查看精确时间与时区；打开资源窗口也能直接看到完整配置修改时间。
- 历史缺失显示“未记录”。GitHub 拉取未变资源保留已知修改时间；新增或变更资源的原始修改时间无法确定，不用拉取时间代替，下一次在本站保存后开始记录。

**当前远程来源在保存规则集时刷新；更新周期设置尚不触发后台定时抓取。** 保存失败或发生冲突不会发布新时间。SRS 构建和重试不改变配置修改时间。

## 订阅与规则集链接

配置订阅包含访问 Token，请只提供给需要使用它的客户端。重置订阅 Token 后，旧配置链接失效，需要重新复制。规则集 JSON/SRS 链接公开可读，不要放入私密规则。

不启用 SRS 时可以使用 JSON。启用 SRS 后，规则集卡片显示编译状态和可用格式；编译失败可以重试，已有可用 SRS 会继续保留。设置与权限见 [SRS 编译器](https://github.com/Leovikii/Sing-Sub/blob/main/docs/operations/srs-compiler.md)。

## GitHub 同步

GitHub 是可选的私有数据备份与编辑渠道，普通资源编辑不需要连接 GitHub。在设置中连接私有仓库后，从同步页选择方向：

- **推送**：以本站数据更新 GitHub 受管文件。
- **拉取**：以 GitHub 文件更新本站数据，完成后刷新页面中的配置和资源。

首次同步、双方都修改或反向覆盖时，会要求确认覆盖目标。确认前检查差异；取消不执行同步。同步不自动合并双方内容，无效文件会被拒绝。详细权限与恢复说明见 [GitHub 同步](https://github.com/Leovikii/Sing-Sub/blob/main/docs/operations/github-sync.md)。
