# 3.1.4 交付范围

用户已授权更新版本、清理文档与无用代码，推送 dev 并创建到 main 的 PR；不合并、不部署、不发布 Release。

- 资源卡片：名称、两行备注、底部时间；近期相对时间，满 30 天绝对时间；精确日期与时区可访问。Profile 动态配置卡片不加时间。
- 规则集：来源时间保留 SOURCE 左下；配置修改、来源抓取与 SRS 构建分开。当前按保存刷新，不新增定时调度。
- 数据：透出已有 updatedAt；拉取未变资源保留时间，未知历史不伪造；不改变 schema、revision/CAS、同步覆盖或编译语义。
- 文档：用户 README/Wiki 与 Agent 工程入口分离；保留现行约束和精炼历史，旧计划与流水由 Git 追溯。
- 版本：package/lockfile、应用、README 项目版本与版本测试统一 3.1.4；版本号不代表已部署。旧 v2 安装仍须先经过 3.1.2。
- 验收：lint、许可证、全部类型、unit/integration、构建、包预算、Worker dry-run 与 Chromium；Firefox 本机启动故障由 PR 的 Linux CI 补验，不跳过 gate。

详细语义见 ADR-064，当前结果见 [progress](./progress.md)。
